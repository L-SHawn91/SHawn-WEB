# EXPERT_BLOG_TEMPLATE_V1 사용 가이드

## 목적
- 전문가 톤 고정
- 메타/OG 기본 탑재
- 시각화 3종(비교 차트/실행 플로우/KPI) 매 글 기본 포함
- 공개 고지 영역은 필요할 때만 별도 검토

## 필수 치환 변수
- `{{TITLE}}`, `{{H1_TITLE}}`, `{{META_DESCRIPTION}}`, `{{META_KEYWORDS}}`
- `{{TLDR_1LINE}}`, `{{TLDR_BULLET_1..3}}`
- `{{MAIN_BODY_LEFT}}`
- `{{CHECK_1..4}}`
- `{{FAQ_Q1}}`, `{{FAQ_A1}}`, `{{FAQ_Q2}}`, `{{FAQ_A2}}`

## 공개 글 체크리스트
1. 제목에 핵심 키워드 1~2개 포함
2. description 140~170자
3. 본문 내부링크 2개 이상
4. FAQ 2문항 이상
5. 시각화 캡션/alt 역할 텍스트 유지
6. 내부 운영명과 비공개 자료가 공개 본문에 섞이지 않는지 확인
